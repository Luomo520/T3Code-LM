# T3Code-LM Windows 受控端

本程序为 T3Code-LM 的独立 Windows x64 组件。配对后，T3Code-LM 会话可以发起拍摄请求、打开或激活 T3Code-LM 或记事本，以及正常关闭由受控端创建的窗口。Windows 用户在本机批准请求，并在本机选择拍摄和操作目标。

## 使用

1. 在 Windows 10 或 11 x64 上运行安装程序，从开始菜单打开「T3Code-LM Windows 受控端」。应用使用当前 Windows 用户权限，需要 .NET Framework 4.8 或更新版本。
2. 从 T3Code-LM 的设备控制界面生成 Windows 配对码。输入服务根地址、设备名称和配对码。公网使用 HTTPS。位于受信任局域网的私有 IP 地址可以使用 HTTP，首次配对时会显示明文传输提示。
3. 选择「恢复接收」。关闭主窗口会收起到通知区域。暂停、退出或 Windows 锁定会停止接收操作。配对记录通过 Windows DPAPI 保存到当前用户的本地应用数据。
4. 会话请求截图后，在 Windows 确认并从列表选择窗口或显示器。PNG 截图最长边最多 1440 像素，返回原会话。「截取画面」可单独在本机选择目标并保存 PNG。所选窗口关闭、最小化、改变大小、缩放比例或所在显示器时，结束本次拍摄。
5. 「开始录制」会让你选择本机窗口或显示器、录制时长和 AVI 保存位置。录制时窗口和通知区域会显示状态，可在任一处停止。关闭或最小化受控端、锁定 Windows 或断开会话也会停止。录像无音频，本机单段最多 10 分钟或 500 MB。会话请求录制时，Windows 可选择较短时长，默认最多 10 秒，会话可请求最多 30 秒，文件上限为 5 MiB。正常停止后的录像可从原会话下载。锁定、暂停接收或拍摄目标改变时，已保存的内容留在本机。
6. 选择「设备自检」可检查配对连接、刷新并查看实际读到的硬件和网卡资料。设备名称可在受控端或 T3Code-LM 的设备详情修改，按原配对设备同步。
7. 会话可请求受控端选择本机文件并发回，或在 Windows 保存原会话已附加的文件。受控端显示文件选择或保存窗口，单次最多 5 MiB。接收成功后，原会话记录本机保存路径和 SHA-256。收到受控端发来的文件可在原会话下载。
8. 会话请求打开 T3Code-LM 或记事本时，可以在本机启动该应用，或从该应用的可见窗口中选一个激活。可用的现有窗口出现在 Windows 本机的选择框。关闭请求仅适用于受控端成功创建并仍可确认身份的原窗口。
9. 会话可以读取或填写在 Windows 本机选定的记事本编辑区。填写前，本机显示会替换编辑区的确切文字。编辑区失去前台、无法识别或不支持写入时，操作结束并报告原因。文字只通过原会话的读取和填写结果返回。
   本机 Windows-MCP 可用时，受控端通过 `http://127.0.0.1:8000/mcp` 查询 `ControlStatus`。Windows-MCP 报告本机正在操作时，受控端等待本机空闲，最长约 12 秒，原请求到期或前台改变时提前结束。服务未安装、停用或初次查询失败时，受控端仍校验当前批准及窗口身份。
10. 保存原会话发来的 MSI 后，可在受控端选择「打开安装器」，核对文件与来源并在 Windows 确认。安装器结束后，原会话可查看安装结果。如果受控端退出或 Windows 重启，重新选择「恢复接收」后可继续提交这次安装的回执。恢复时只读取安装登记，证据不足则显示「尚未核实」。
11. 从受控端选择「解除配对」后退出，再从 Windows 的「已安装的应用」卸载。设备也可以在 T3Code-LM 的设备控制界面撤销。

## 构建

在 Windows PowerShell 中使用已有 NSIS 3.04 或兼容版本。

```powershell
.\build.ps1 -MakeNsis 'C:\Path\To\makensis.exe'
```

成品位于 `build/T3Code-LM-Companion-0.2.5-1-Windows-x64-Setup.exe`。WinForms 提供原生窗口与通知区域，.NET Framework 提供 HTTPS 和 DPAPI，Win32 提供截图，NSIS 提供按用户安装和卸载。安装程序采用应用版本 0.2.5-1，Windows 文件版本为 0.2.5.1。

`CompanionWindow.cs` 负责界面、配对和本机确认。 `CaptureChoice.cs` 和 `CaptureTarget.cs` 负责本机目标选择、校验和拍摄。 `Transport.cs` 负责服务器协议和配对记录。 `DesktopWindowChoice.cs` 和 `WindowsDesktop.cs` 负责选择及操作固定应用的窗口，`WindowsMcp.cs` 查询本机接管状态。 `Recording.cs` 负责写入本机 MJPEG AVI。
